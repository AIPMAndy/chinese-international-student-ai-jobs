# 02｜能力差距表

版本：2026-11-13。用途：找出“不会、会讲但不会做、能做但无证据”分别卡在哪里。

## 填写说明

先完成[岗位研究](01-job-research.md)，选 3–5 个同路线、资格可行的岗位。每项能力都写一个可观察任务。参考[基础诊断章节](../docs/02-gap-and-learning.md)。

证据等级：0＝不能解释；1＝能解释但不能独立完成；2＝能独立完成但交付不便复核；3＝他人可按文档复现并追问。等级只是安排练习，不是雇主评分或录用概率。

“独立”不是不准查文档。记录哪些部分查了文档、用了 AI、请教了他人；关键是自己能判断结果、修复错误并解释取舍。

## 教学模拟示范

模拟读者能运行模型，却解释不了为什么用 dev 选参数。不要写“机器学习水平 60 分”；记录“实验设计1级：会背三种划分名称，不能证明 test 没参与选择”。最小动作是复跑基线，指出代码中选参的数据来源，新增一个拒绝训练集混入 test 的检查，并保留运行记录。

另一种情况是读者本来能写接口，但没有 README。缺口属于“证据”，本周应整理接口契约与错误样例，不必重新上完整后端课程。以上均为教学模拟。

## 验收标准

- 每个缺口都对应目标岗位，不能只列热门技能名。
- 每个等级都有一次实际任务或证据支撑。
- 最多三个当前重点，能在现有时间预算内完成。
- 完成后用相同任务复测；记录变化，未通过就保持原等级。
