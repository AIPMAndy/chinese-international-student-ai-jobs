# 05｜把项目变成 GitHub、简历与面试证据

同一个项目需要三种表达：GitHub 让人复现，简历让人快速判断相关性，面试让人验证你的理解。三者应使用同一组事实，不能为了看起来高级而各写一套结果。

## GitHub 首屏只回答六个问题

1. 这个项目解决什么具体问题？
2. 输入是什么，来自哪里，许可是什么？
3. 最短运行命令是什么？
4. 输出在哪里，怎样判断对错？
5. 相比基线，改了什么，付出什么代价？
6. 你的贡献、AI 辅助和未解决问题分别是什么？

把环境、依赖和命令放前面。不要把全部结果藏在十层 notebook 或视频里。输出原始 JSON/CSV、测试和失败样本，让招聘方有选择地核验。截图是辅助证据，不能替代代码和可重复运行步骤。

## 推荐的展示顺序

**一句话问题 → 快速开始 → 实测结果 → 方法与对照 → 失败与限制 → 贡献与许可。** 在结果旁写明这是合成数据、本地环境和教学用途。你可以置顶最相关的两个项目，无须把每门课程都塞进主页。

这不是要求你修改个人主页。本项目只提供你自己展示作品的方法，实际申请时再由你决定如何整理个人仓库。

## 简历项目句子的四个要素

**动作 + 技术对象 + 可核验结果 + 范围。** 例如：“在人工构造的工单数据上实现多项式朴素贝叶斯分类基线，固定 train/dev/test 分割并输出逐类 F1 和失败样本；结果以仓库报告为准。”

这句话适合描述你确实完成的教学实践。原样运行本仓库时，动作应写“复现”；独立新增模块后才写“实现”。没有真实线上数据，不写“提升业务效率”“降低运营成本”“服务数万用户”。

## 三条路线的表达重点

| 路线 | 简历最先写 | 必须能回答 | 少写什么 |
| --- | --- | --- | --- |
| 算法 / ML | 任务、数据分割、基线、模型与结果 | 分母、泄漏、误差、消融、泛化 | 无定义的“准确率显著提升” |
| AI 工程 | 服务契约、可靠性、性能测量条件 | p95怎么测、并发多少、错误如何处理 | 堆满云平台名称 |
| AI 应用 | 任务评测、检索/生成边界、失败回退 | 可回答覆盖与拒答、引用是否支持结论 | “基于Agent打造智能平台”但无测试 |

## 教学模拟：从空话到可信陈述

**原句：**“精通 AI、大模型和 RAG，独立开发企业级智能客服，准确率 99%。”

**问题：**没有数据、分母、评测边界和部署证据；“精通”“企业级”不可直接核验；99% 可能来自自己挑的样本。

**改写示范：**“复现离线检索问答教学基线，使用人工构造文档与独立测试问题，分别检查检索命中、回答覆盖和不可回答问题拒答；保留答非所问失败样本，并实现一项经评测验证的改动。”

最后半句只有真的新增并验证后才保留。完整中文与英文示范见模板包，不要直接把教学数值放入自己的履历。

## 英文表达：先说限制，反而更容易讲清

可以用短句：“This is a local educational project using synthetic data. I reproduced the baseline, then changed the retrieval threshold. I evaluated the change on a fixed test set. It improved one metric but reduced answer coverage.”

这些句子是结构示范。要改成真实做过的行为与实际指标。不要把 API-based application 写成 trained a foundation model；不要把实现部分模块写成 led the whole platform。

## 90 秒项目讲解

- **0–15 秒：**目标用户或技术问题、为什么要做。
- **15–30 秒：**数据与约束，包括不能做的事。
- **30–50 秒：**基线、你的改动和选择理由。
- **50–70 秒：**结果、比较条件和一条失败。
- **70–90 秒：**本人贡献、限制、下一步如何验证。

接着准备五分钟和十五分钟版本。五分钟解释完整链路，十五分钟能打开核心代码、指标定义和失败输入。面试官打断时先回答问题，不要机械背稿。

## 发布前的五次自查

**真实性：**所有学校、日期、职务、数字都是自己的事实。**授权：**课程、公司、同伴和第三方材料可以公开。**一致性：**简历、README、报告使用相同版本。**可运行：**从新目录复现。**可解释：**你能修改一个边界条件，重新评测并解释变化。

有些公开申请系统会解析简历，格式和文件要求以该岗位页面为准。保持文字可选、标题清晰、联系方式明确；不要把整份简历做成图片。上传前自己重新打开最终 PDF，确认链接、字体和页序。
